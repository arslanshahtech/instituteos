# PROMPT 08 — ATTENDANCE, EXAMS & ASSIGNMENTS

Execute only the learning-performance domain.

## Attendance

Implement:
- attendance records
- present
- absent
- late
- excused if supported
- attendance history
- class summary
- student percentage
- teacher entry
- admin reporting

## Exams/results

Implement:
- exam types
- exams
- exam schedule
- subjects
- marks
- grading rules
- grades
- results
- report-card data
- performance summaries

## Assignments

Implement:
- assignment creation
- due dates
- instructions
- student submissions
- status
- teacher feedback
- submission history

Do not build a full LMS.

## Security

Teachers can modify only permitted classes/students.

Students cannot modify teacher/admin records.

Parents only see permitted child data.

## Acceptance criteria

- attendance workflow works
- statistics are correct
- exams/results work
- grades are consistent
- assignments work
- role/tenant security remains intact
- tests cover important edge cases
